# Краткий отчет

## Идея игры

Игра называется **Ice Courier**. Игрок управляет зимним курьером, который ловит падающие магические кристаллы и уворачивается от опасных треснувших ледяных плит. Есть два режима: классический режим с целью 15 очков и бесконечный режим на рекорд с растущей сложностью.

## Нейросети

- ChatGPT/Codex: идея, стартовая структура JavaScript-кода, помощь с рефакторингом и проверкой требований.
- OpenAI image generation: фон игры, спрайт-лист игрока из 3 кадров, кристалл, препятствие.

## Браузеры

Проверка заявлена в коде для Google Chrome и Mozilla Firefox. Игра использует локальные PNG-файлы, Canvas API, `requestAnimationFrame`, обработчики клавиатуры и мыши без внешних библиотек.

## Самая сложная часть

Самой сложной частью была настройка игрового цикла: нужно было одновременно обновлять движение игрока, падение объектов, столкновения, счёт, жизни, победу/поражение, режим рекорда, рост сложности и перезапуск так, чтобы игра не зависала при быстрых нажатиях.
